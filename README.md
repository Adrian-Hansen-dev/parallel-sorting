# Exercise 3: Task Parallelism – Parallel Sorting

Um das Programm mit OpenMP-Unterstützung zu kompilieren, verwende folgendes Kommando im Terminal:

```bash
g++ -fopenmp src/main.cpp -o sorting_app
```

*Hinweis: Das Flag `-fopenmp` ist zwingend erforderlich, damit die `#pragma omp`-Anweisungen vom Compiler verarbeitet werden.*

## Ausführung

Du kannst das Programm nach dem Kompilieren wie folgt starten:

```bash
./sorting_app
```
